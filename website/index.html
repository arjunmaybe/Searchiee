01 / Search

Meaning, not exact matches.

A keyword search asks whether your words appear. Searchiee asks which indexed files are closest in meaning.

Each selected Markdown or text file is embedded as a whole with FastEmbed. A query is embedded the same way, then compared with every indexed file. Searchiee returns one result per file, ranked by cosine similarity, with a short snippet and score.

Searchiee points back to your files; it does not generate answers. The similarity score is a ranking signal, not a probability.

What one search does

  1. 01
    Embed the query

    The query is converted on your machine with FastEmbed.

  2. 02
    Compare the files

    The query embedding is compared with every indexed file by cosine similarity.

  3. 03
    Return the files

    Up to 10 files appear, each with a snippet and score.

02 / Local

Your files stay where they are.

Searchiee is a desktop tool, not a hosted service. It reads the supported files in the folders you add, builds a local index, and searches that index on your PC.

Processing
FastEmbed runs on your machine. No API key or cloud search call.
Storage
The index holds document contents and embeddings in local app data.
Accounts
None. No sign-in, synchronization, or team workspace.
Telemetry
v0.1.0 contains no telemetry.

First run

Network access is required once to download the roughly 90 MB AllMiniLML6V2 model. After it is cached, indexing and searching work offline.

03 / Scope

A deliberately small scope.

The index is limited to text you point it at, not your whole drive.

You add each folder yourself. Searchiee scans it for Markdown and plain-text files, embeds the text, and keeps the folder in its registry. There is no background watcher: refresh a folder when its files change.

Not in 0.1.0

  • PDFs, Office documents, images, or OCR
  • Background file watching
  • Cloud synchronization or accounts
  • Generated answers or a chat interface
Formats
Markdown (.md) and plain text (.txt), any letter case.
Indexing

Manual. Changed files appear after you refresh the folder.

04 / Install

Searchiee 0.1.0 for Windows.

Use the NSIS installer for a normal desktop install, or the MSI for managed deployment. Both are Windows x64 builds.

  1. Run the installer.

    Windows 10 or 11, x64. WebView2 is normally already present.

  2. Index a folder.

    Open Searchiee, click Index a folder, and enter its path.

  3. Search and refresh.

    Type what you remember. Refresh a folder after its files change.

Before you start

  • Windows 10/11, x64
  • WebView2, normally included with Windows
  • Internet access for the first model download

Node.js and Rust are only needed to build from source, not to use the installer.
