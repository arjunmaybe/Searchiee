Privacy / Searchiee

Privacy and local data.

Searchiee is a desktop app first and a website second. This page covers both, including what stays on your PC and when the app needs network access.

Last updated 22 October 2026

01 / Website

This website

This is a static website. It sets no cookies, runs no analytics, and loads no advertising or third-party scripts. There is no account or search form on the site.

When the site is deployed, the static host and GitHub may process ordinary request data under their own policies. Searchiee does not add tracking beyond that hosting.

02 / Desktop app

The desktop application

Searchiee reads only the folders you add, and only Markdown and plain-text files inside them. It embeds the text locally and stores the result in a local index.

The index lives in Tauri’s application-specific local data directory as index-v1.json. It contains registered folder paths, document paths, document contents, and embedding vectors. It is not uploaded to a Searchiee server, and the current app has no hosted account or cloud-search service.

The current source contains no telemetry. Removing a folder deletes that folder’s index entries, not the original files. Deleting the index resets the saved index and requires re-indexing; your documents stay where they are.

There is no background filesystem watcher. Files are read when you index or refresh a folder, and search runs against the local index.

03 / Network

Model download and offline use

The first indexing or search needs network access to download the FastEmbed AllMiniLML6V2 model, roughly 90 MB. After the model is cached, indexing and searching work offline.

An offline first run is not promised. If the model is not cached and the download cannot complete, the app cannot index or search until the model is available.

04 / Downloads

GitHub Releases

Installers and checksums are delivered through GitHub Releases. Downloading them is a request to GitHub, which may process ordinary request data under its own privacy policy.

The release includes NSIS and MSI installers plus a SHA-256 checksum file .

05 / Contact

Questions and requests

The verified contact channel is Searchiee Issues on GitHub . A dedicated privacy email or legal entity is not currently published.

This statement describes the current website and Searchiee 0.1.0. Update it if the app, hosting, or data handling changes.
